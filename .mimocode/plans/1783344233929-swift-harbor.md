# Fix: connectedPlatforms=null despite fullCampaignData loaded

## Проблема
Диалог публикации показывает "Не подключено" для ВСЕХ платформ, включая YouTube с реальными токенами в БД.
- `connectedPlatforms=null` — `getConnectedPlatforms()` возвращает `null`
- `fullCampaignData=true` — данные кампании загружены (`fullCampaignData?.data` существует)
- `campaignId=4513f574-...` — правильная кампания (omemo.tech с YouTube токенами)
- Console.log не работает — Vite убирает console.log в production сборке

## Root cause (гипотеза)
`getConnectedPlatforms()` не может прочитать `social_media_settings` из `fullCampaignData.data`. Возможные причины:
1. `social_media_settings` отсутствует в ответе API (другое имя поля)
2. `social_media_settings` — JSON-строка вместо объекта (и `JSON.parse` падает)
3. `fullCampaignData.data` имеет неожиданную структуру

## Решение

### 1. Заменить console.log на видимый debug в UI
**Файл:** `client/src/pages/content/index.tsx:3139-3143`

Заменить текущую debug-плашку на детальную:
```
campaignId: {selectedCampaignId}
fullCampaignData.data keys: {fullCampaignData?.data ? Object.keys(fullCampaignData.data).join(', ') : 'NULL'}
social_media_settings type: {typeof fullCampaignData?.data?.social_media_settings}
social_media_settings: {JSON.stringify(fullCampaignData?.data?.social_media_settings)?.slice(0, 500)}
connectedPlatforms: {JSON.stringify(connectedPlatforms)}
```

### 2. Поправить `getConnectedPlatforms()` с fallback
**Файл:** `client/src/pages/content/index.tsx:485-515`

Добавить:
- Обработку ошибок при `JSON.parse` (try/catch)
- Fallback на все возможные имена полей
- Если `campaignData` существует но `social_media_settings` нет — вернуть объект со всеми `false` вместо `null`

### 3. Проверить серверный ответ API
**Файл:** `server/routes/campaigns.ts:214-227`

Убедиться что `res.json({ success: true, data: campaign })` действительно содержит `social_media_settings` и это объект.

## Верификация
1. Открыть диалог публикации → посмотреть debug-плашку → увидеть keys, type, value
2. Если `social_media_settings` — строка → JSON.parse починит
3. Если `social_media_settings` отсутствует → искать причину в API
4. YouTube должен стать доступен для выбора
