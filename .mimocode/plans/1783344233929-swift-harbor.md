# План: Улучшение UX выбора трендов и комментариев

## Проблема
1. Клик по тренду открывает TrendDetailDialog вместо выбора тренда для просмотра комментариев
2. Чекбокс маленький и непонятный — непонятно что он делает
3. Таб "Комментарии" не активируется автоматически при выборе тренда

## Решение

### 1. Клик по карточке = выбор тренда для комментариев
**Файл:** `client/src/pages/trends/index.tsx` (~строка 2643)

Текущий код:
```tsx
onClick={() => {
  setSelectedTrendTopic(topic);
  toggleTopicSelection(topic);
  loadTrendComments(topic.id);
}}
```

Нужно убрать `toggleTopicSelection` и оставить только выбор для просмотра + авто-переключение на таб комментариев:
```tsx
onClick={() => {
  setSelectedTrendTopic(topic);
  setActiveTab('comments');
  loadTrendComments(topic.id);
}}
```

### 2. Чекбокс = только пакетный сбор (отдельно от просмотра)
**Файл:** `client/src/pages/trends/index.tsx` (~строка 2655)

Сделать чекбокс крупнее, с label и визуально отделить от карточки:
```tsx
<div className="flex items-center gap-2 p-1 rounded hover:bg-accent">
  <Checkbox
    checked={selectedTopics.some(t => t.id === topic.id)}
    onCheckedChange={() => toggleTopicSelection(topic)}
    className="h-5 w-5"
    onClick={(e) => e.stopPropagation()}
  />
  <span className="text-xs text-muted-foreground whitespace-nowrap">Пакетный сбор</span>
</div>
```

### 3. Убрать диалог TrendDetailDialog при клике
**Файл:** `client/src/pages/trends/index.tsx`

Убрать `setPreviewTrendTopic(topic)` и вызов диалога из обработчика клика по карточке. Оставить только просмотр поста по внешней ссылке.

### 4. TrendsList.tsx — аналогичное изменение (если используется)
**Файл:** `client/src/components/TrendsList.tsx` (~строка 487)

Card onClick вызывает диалог — переключить на выбор тренда:
```tsx
onClick={() => {
  onSelectTrend?.(trend);
}}
```

Добавить проп `onSelectTrend` в интерфейс.

## Файлы для изменения
- `client/src/pages/trends/index.tsx` — основные изменения
- `client/src/components/TrendsList.tsx` — проп + клик

## Верификация
1. Клик по карточке тренда → таб "Комментарии" открывается с данными тренда
2. Чекбокс виден с подписью "Пакетный сбор"
3. Чекбокс добавляет тренд в пакет для массового сбора комментариев
4. Ссылка на пост работает через иконку внешней ссылки
