# План: Локализация ошибок генерации изображений

## Проблема
Ошибки API (OpenAI, Gemini, FAL) приходят на английском и отображаются как есть. Интерфейс на русском/английском/испанском, а ошибки — только на языке провайдера.

## Архитектура
- **Frontend**: i18next, язык в `localStorage('language')`, дефолт `ru`
- **Backend**: ошибки хардкожены на русском, передаются как `{ error: "..." }`
- **Locale не передаётся** в API запросы (кроме report export)

## Решение

### 1. Frontend передаёт локаль в API запросы
**Файл:** `client/src/lib/api.ts`

Добавить `x-locale` header в axios interceptor:
```ts
const locale = localStorage.getItem('language') || 'ru';
config.headers['x-locale'] = locale;
```

### 2. Backend читает локаль и возвращает локализованные ошибки
**Файл:** `server/utils/locale-errors.ts` (новый)

Создать утилиту с маппингом ошибок на 3 языка:
```ts
export function localizedError(key: string, locale: string = 'ru'): string {
  const errors: Record<string, Record<string, string>> = {
    'openai_billing': {
      ru: 'Достигнут лимит расходов OpenAI. Пополните баланс в настройках биллинга.',
      en: 'OpenAI billing hard limit reached. Please top up your balance in billing settings.',
      es: 'Límite de facturación de OpenAI alcanzado. Recargue su saldo en la configuración de facturación.',
    },
    'openai_quota': { ... },
    'openai_rate_limit': { ... },
    'openai_invalid_key': { ... },
    'key_not_found': { ... },
    'timeout': { ... },
    'generic': { ... },
  };
  return errors[key]?.[locale] || errors[key]?.['en'] || errors[key]?.['ru'] || key;
}
```

### 3. Маппинг ошибок OpenAI
**Файл:** `server/services/openai-image.ts`

Заменить хардкоженные сообщения на вызов `localizedError()`:
```ts
// Было:
return { success: false, imageUrls: [], error: detail };

// Стало:
const errorKey = mapOpenaiError(detail); // 'openai_billing', 'openai_quota', etc.
return { success: false, imageUrls: [], error: localizedError(errorKey, locale) };
```

Маппинг ключей:
| OpenAI текст | Ключ |
|---|---|
| `Billing hard limit has been reached` | `openai_billing` |
| `You exceeded your current quota` | `openai_quota` |
| `Rate limit reached` | `openai_rate_limit` |
| `Invalid API key` | `openai_invalid_key` |

### 4. Маппинг ошибок сервера в routes/ai.ts
**Файл:** `server/routes/ai.ts`

Заменить хардкоженные русские строки на `localizedError()`:
- Строка ~200: `"API ключ OpenAI не найден"` → `localizedError('key_not_found', locale)`
- Строка ~337: Timeout, rate limit ошибки → `localizedError(...)`

### 5. Frontend — убрать хардкоженные русские строки
**Файл:** `client/src/components/ImageGenerationDialog.tsx`

В `onError` обработчике (строка ~665):
- Убрать хардкоженные `"Ошибка генерации"`, `"Генерация изображений доступна только на платном плане"`
- Использовать `t('errors.generationError')` или просто выводить `serverMsg` (он уже локализован на бэкенде)

Добавить ключи в локали:
**Файлы:** `client/src/locales/ru.json`, `en.json`, `es.json`
```json
"errors": {
  "generationError": "Ошибка генерации / Generation error / Error de generación",
  "generationErrorDesc": "...",
  "subscriptionRequired": "..."
}
```

### 6. Аналогично для Gemini ошибок
**Файл:** `server/services/gemini-image.ts` и `server/services/gemini-direct.ts`

Добавить маппинг ошибок Gemini (billing, quota, safety block) через `localizedError()`.

### 7. Аналогично для FAL ошибок
**Файл:** `server/services/fal-ai-universal.ts`

FAL проксирует ошибки OpenAI — маппинг уже будет работать через openai-image.ts.

## Файлы для изменения
1. `server/utils/locale-errors.ts` — **новый** файл с маппингом ошибок
2. `client/src/lib/api.ts` — добавить `x-locale` header
3. `server/services/openai-image.ts` — маппинг ошибок OpenAI
4. `server/routes/ai.ts` — локализация ошибок генерации
5. `client/src/components/ImageGenerationDialog.tsx` — убрать хардкоженные строки
6. `client/src/locales/ru.json`, `en.json`, `es.json` — добавить ключи ошибок

## Верификация
1. Сменить язык на English → сгенерировать картинку с невалидным ключом → ошибка на английском
2. Сменить язык на Español → та же ошибка → на испанском
3. На русском → проверить что ничего не сломалось
4. Проверить что ошибки OpenAI (billing limit) показываются корректно
