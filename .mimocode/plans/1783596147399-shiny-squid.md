### 1. Feature flag не показывает аккордеон
Текущий код в `campaigns/[id].tsx` (строки 73-84) пытается достать email из JWT:
```typescript
const { user, isLoading: isAuthLoading } = useAuth();
let featureUserEmail: string | null = null;
try {
  const token = localStorage.getItem('auth_token');
  if (token && token.includes('.')) {
    const payload = JSON.parse(atob(token.split('.')[1]));
    featureUserEmail = payload.email || null;
  }
} catch {}
const isStyleFeatureEnabled = !isAuthLoading && !!featureUserEmail && STYLE_FEATURE_EMAILS.includes(featureUserEmail);
```
**Проблема**: `featureUserEmail` всегда `undefined` → аккордеон скрыт. Debug-баннер тоже не рендерится (early return на строке 840: `if (!campaign && !isLoading)` срабатывает до render).

**Рекомендация**: временно убрать feature flag (`const isStyleFeatureEnabled = true`), чтобы проверить что фича работает. Потом вернуть whitelisting через более надёжный способ.
