# План развития проекта SMM Manager (Magnus's Roadmap)

## 1. 🧪 Тестирование и Качество (Ближайший фокус)
- [x] **Добить покрытие соцсетей:** Реализованы тесты для `Facebook`, `Instagram Reels`, `TikTok`, `VK Clips`, `YouTube`.
- [x] **Добить 80%+ покрытия:** Покрыты ключевые инструменты `autonomous-ai.ts` (tool implementations).
- [x] **Интеграционные тесты:** Реализованы Full-Cycle тест и тесты планировщика (Scheduler) с защитой от дублей.
- [ ] **Mock-сервер для API:** Создать полноценный мок для внутренних API, чтобы `AIAssistant` мог гонять тесты без реального бэкенда.

## 2. 🤖 AI Ассистент (Улучшение мозгов)
- [ ] **Расширение Function Calling:** Добавить в `autonomous.ts` поддержку работы с медиа-файлами (удаление, замена картинок в постах через команды).
- [ ] **Long-term Memory:** Реализовать суммаризацию диалогов в `ai-conversation-storage.ts`, чтобы ассистент не забывал контекст длинных сессий.
- [ ] **Обработка ошибок:** Улучшить `handleStepError` в workflow. Сейчас там только retry для анкеты. Нужно добавить восстановление для ошибок генерации изображений.

## 3. 📱 Интеграции и Соцсети
- [x] **Support Chat:** Интегрирован Telegram Bot для уведомления админа о новых обращениях в поддержку.
- [x] **Стабильность токенов:** Реализована система автоматической фоновой валидации токенов (раз в 6 часов) с уведомлением в Telegram.
- [ ] **Унификация:** Привести `tiktok-service.ts` и `vk-clips-service.ts` к единому интерфейсу `BaseService` (сейчас есть расхождения).

## 4. ⚙️ Инфраструктура и DevOps
- [ ] **Очистка мусора:** Настроить скрипт для удаления временных файлов генерации из `/tmp` и S3, которые копятся после неудачных попыток.
- [ ] **Swagger Sync:** Автоматизировать обновление `swagger.ts` при изменении роутов, чтобы документация не тухла.
- [ ] **Healthcheck:** Добавить эндпоинт `/api/health`, который проверяет связь с Directus, Redis и S3.

## 5. ✨ Новые фичи (Backlog)

- [ ] **A/B Генерация:** Команда "Предложи 3 варианта этого поста с разными стилями".
