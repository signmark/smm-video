# Стратегия развития SMM Manager: Magnus's Vision

Этот документ описывает ключевые архитектурные и функциональные улучшения, необходимые для превращения проекта в стабильный production-ready продукт.

## 1. Фундаментальная надежность (Stability First)
### 🩺 Система самодиагностики (Health Checks)
- **Что добавить:** Эндпоинт `/api/health`, который проверяет не только статус сервера, но и доступность всех внешних зависимостей: Directus, Redis, S3 (Beget), n8n.
- **Зачем:** Для быстрого обнаружения проблем (например, когда S3 отвалился, а мы пытаемся генерировать контент).

### 🛡️ Умная валидация токенов
- **Что добавить:** Фоновая задача, которая раз в 6-12 часов проверяет валидность токенов (FB, VK, YouTube) и уведомляет пользователя через Telegram-бота, если токен протух.
- **Зачем:** Сейчас публикация падает "в моменте", когда планировщик уже запустил процесс. Лучше знать об этом заранее.

### 🧹 Автоматическая очистка (Housekeeping)
- **Что добавить:** Cron-скрипты для удаления временных файлов из `/tmp` и неудачных генераций из S3.
- **Зачем:** Сейчас проект копит "мусор" после каждой ошибки генерации, что со временем съест место на диске.

---

## 2. Эволюция AI-Ассистента (Smart Automation)
### 🧠 Долгосрочная память (Long-term Memory)
- **Что добавить:** Модуль суммаризации в `ai-conversation-storage.ts`. Каждые 50 сообщений AI должен создавать "краткое содержание" контекста.
- **Зачем:** Чтобы ассистент не забывал, о чем вы договорились в начале создания кампании, когда контекстное окно переполнится.

### 🎥 Продвинутый медиа-менеджмент
- **Что добавить:** Расширение команд для работы с картинками: "Магнус, удали вторую картинку в этом посте", "Замени фото на более яркое".
- **Зачем:** Сейчас AI может только создавать, но не редактировать структуру вложений в существующих черновиках.

---

## 3. Функциональное расширение (New Features)
### ✂️ Авто-ресайз и Кроп
- **Что добавить:** Интеграция с `sharp` или внешним API для автоматической обрезки сгенерированных изображений под форматы:
  - Instagram Stories (9:16)
  - Facebook Feed (1:1)
  - YouTube Thumbnails (16:9)
- **Зачем:** Чтобы пользователю не приходилось вручную подгонять картинки под требования платформ.

### 📮 Интеграция Support Chat
- **Что добавить:** Завершить реализацию в `support.ts` — проброс сообщений из чата поддержки напрямую в Telegram-бота админу.
- **Зачем:** Чтобы оперативно отвечать пользователям прямо из мессенджера.

### 👥 Мульти-аккаунты
- **Что добавить:** Возможность привязать несколько страниц Facebook или каналов Telegram к одной кампании.
- **Зачем:** Сейчас кампания жестко ограничена одним аккаунтом на платформу.

---

## 4. План реализации (Timeline)

### Этап 1: Стабилизация (1-2 недели)
1. Реализация Health Check.
2. Система предварительной проверки токенов.
3. Настройка автоматической очистки мусора.

### Этап 2: Улучшение AI (2-3 недели)
1. Внедрение Long-term Memory.
2. Команды для редактирования медиа-вложений через чат.
3. Улучшение `handleStepError` (авто-ретраи при сбоях генерации).

### Этап 3: Масштабирование (1 месяц+)
1. Авто-ресайз изображений.
2. Мульти-аккаунты.
3. Полноценный Support-чат.
