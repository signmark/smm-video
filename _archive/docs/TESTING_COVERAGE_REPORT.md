## Как запустить тесты

```bash
# Запуск всех тестов
npx jest

# Запуск конкретного теста
npx jest facebook-token-validation.test.ts

# Запуск с покрытием
npx jest --coverage

# Запуск в watch режиме
npx jest --watch
```
