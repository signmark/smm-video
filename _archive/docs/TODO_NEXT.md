# План на завтра (понедельник)

1. **Обучить тестера полному циклу генерации**
   - Выбор типа контента.
   - Ввод текста.
   - Вызов генератора изображений.
   - Выбор 1 из 3 сгенерированных картинок.
   - Сохранение результата.

2. **Проверить статусную логику аккордеонов**
   - Убедиться, что зеленые галочки корректно отображают статус завершения этапов.

3. **Прогнать тест для типа "Текст с картинкой" до статуса PASS**
   - Исправить возможные ошибки в процессе публикации и достичь успешного прохождения теста.
