# SMM Manager — Product Vision

## Миссия

Дать SMM-специалистам, фрилансерам и агентствам инструмент, который берёт на себя рутину: сбор трендов, генерацию контента, адаптацию под платформы и публикацию по расписанию — чтобы человек занимался стратегией, а не копипастой.

---

## Целевая аудитория

| Сегмент | Боль | Что даёт платформа |
|---------|------|--------------------|
| Фрилансер (1–15 клиентов) | Не успевает закрывать все проекты | Контент-план на неделю за 30 минут |
| SMM-агентство | Хаос при масштабировании | Единая среда для команды с разными ролями |
| Бренд-менеджер | Зависимость от подрядчиков | Автономный AI-режим 24/7 |
| Маркетолог (B2B) | Нет инструмента для LinkedIn/YouTube | Мультиплатформенная публикация |

---

## Ключевые ценности продукта

### 1. AI как соавтор, а не шаблонизатор
Контент генерируется на основе реального контекста: анкеты бизнеса, собранных трендов, аналитики прошлых публикаций. Не «напиши пост», а «напиши пост для фитнес-клуба в Москве, аудитория 25–40 лет, тема — актуальный тренд недели».

### 2. Полный цикл в одном окне
Тренды → контент → изображения → планирование → публикация → аналитика. Без переключения между 5–7 разными сервисами.

### 3. Автономный режим — реальный, не маркетинговый
AI может вести SMM-кампанию самостоятельно неделями: собирать тренды, генерировать и публиковать контент по расписанию, уведомлять о результатах в Telegram. Режим `controlled` позволяет согласовывать план до публикации.

### 4. Видео как первоклассный формат
Отдельный подпроект Video App — полный пайплайн от темы до MP4: сценарий, стоковые или AI-сгенерированные кадры, озвучка, музыка, финальная склейка. Не редактор — генератор.

### 5. Мультиплатформенность без боли
Instagram, VK, Telegram, Facebook, YouTube, Threads, TikTok — с учётом ограничений каждой платформы (лимит символов, форматы медиа, правила API).

## Текущее состояние продукта (как есть)

### Реализовано
- Управление кампаниями (анкета бизнеса, ключевые слова, настройки платформ)
- Сбор трендов из Telegram, VK, Instagram, YouTube через Scraper API + Pexels
- AI-генерация текста: Gemini 3.5 Flash / 3.0 Pro / 2.5 Pro → DeepSeek → Qwen (fallback-цепочка)
- AI-генерация изображений: Imagen 4 / Gemini Flash / FAL.AI (Flux, Juggernaut XL, SDXL)
- Публикация: Telegram, VK, VK Stories/Clips, Instagram, Instagram Reels, Facebook, Threads, YouTube, TikTok
- Планировщик с 4-уровневой защитой от дублей, ретраями, автовосстановлением
- Автономный режим (8 фаз цикла, 3 режима: full_auto / controlled / mixed)
- AI-ассистент с 28 инструментами и Function Calling
- Stories-редактор (1080×1920, градиенты, текст)
- Video App: сценарий → stock/AI-кадры → анимация FAL.AI → TTS → музыка → MP4
- Telegram Mini App
- Аналитика: ER, лучшее время, топ-посты

### В процессе / известные ограничения
- Аналитика подтягивается из метаданных публикаций, прямой API-интеграции с соцсетями для метрик пока нет
- Командная работа (роли, апрувы) — не реализована
- A/B тестирование постов — не реализовано

- [ ] Предиктивная аналитика — AI оценивает потенциал поста до публикации

## Принципиальные архитектурные решения

| Решение | Причина |
|---------|---------|
| Directus как auth + CMS | Готовый RBAC, PostgreSQL под капотом, не нужно писать свой auth |
| API-ключи хранятся в Directus, не в .env | Управление ключами на уровне пользователя/кампании без деплоя |
| Dev раздаёт production build | Совместимость с Telegram Mini App (кэш WebApp требует стабильных URL) |
| Публикатор — singleton с mutex | Исключает дубли при горизонтальном масштабировании и ретраях |
| Video App — отдельный сервер (порт 3001) | Изоляция тяжёлого ffmpeg-процессинга от основного API |
