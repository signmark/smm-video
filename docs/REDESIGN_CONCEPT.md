# SMM Manager — Концепция редизайна

## Проблемы текущего UI

По итогам работы с платформой выявлены следующие болевые точки:

1. **Перегруженное боковое меню** — много пунктов, нет чёткой группировки по задачам
2. **Разрозненный флоу** — чтобы создать и опубликовать пост, нужно пройти 4–5 разных экранов без явного «следующего шага»
3. **Слабая обратная связь при ошибках** — сырые технические сообщения вместо понятных подсказок
4. **Video App — отдельный остров** — пользователь не понимает, что это часть той же платформы
5. **Мобильный опыт вторичен** — ряд диалогов не адаптирован под маленький экран

---

## Концепция нового дизайна

### Принцип: «Задача, а не раздел»

Навигация строится вокруг того, **что хочет сделать пользователь**, а не вокруг технических разделов системы.

```
Сейчас:                         После редизайна:
─────────────────────           ─────────────────────────────
• Кампании                      • Создать контент  (быстрый старт)
• Тренды                        • Планировщик      (календарь + очередь)
• Контент                       • Аналитика        (дашборд)
• Посты                         • Источники        (тренды + каналы)
• Публикации                    • Настройки        (аккаунты, ключи)
• Аналитика
• Telegram-каналы
• AI-ассистент
• Видео (отдельный сервер)
```

## Ключевые изменения по экранам

### 1. Главный дашборд (новый)

Первое, что видит пользователь после входа — **сводка по активным кампаниям**:

```
┌─────────────────────────────────────────────────────┐
│  Сегодня                                            │
│  ┌──────────────┐  ┌──────────────┐  ┌───────────┐  │
│  │ 3 поста      │  │ 2 тренда     │  │ 1 ошибка  │  │
│  │ запланировано│  │ собрано      │  │ публикации│  │
│  └──────────────┘  └──────────────┘  └───────────┘  │
│                                                     │
│  Следующий пост: «Фитнес-клуб» → Instagram, 18:00  │
│  [Просмотреть]  [Отложить]  [Опубликовать сейчас]  │
└─────────────────────────────────────────────────────┘
```

### 2. Быстрое создание контента (упрощённый флоу)

Вместо прохождения 5 экранов — один диалог-wizard:

```
Шаг 1 из 3: О чём пост?
  [Ввод темы или] [Взять из трендов ↓]

Шаг 2 из 3: Для каких платформ?
  [✓ Instagram] [✓ VK] [ ] Telegram [ ] Facebook

Шаг 3 из 3: Когда публиковать?
  [Сейчас] [Оптимальное время: 18:00] [Выбрать вручную]

[← Назад]  [Сгенерировать →]
```

### 3. Календарь публикаций — центральный экран

Календарь становится главным рабочим экраном, а не второстепенной вкладкой:
- Drag & drop для переноса постов
- Цветовая кодировка по платформам
- Инлайн-редактирование текста прямо в ячейке
- Статусы: черновик / запланирован / опубликован / ошибка

### 4. Video App — интеграция в основной UI

Вместо отдельного сервера с отдельным интерфейсом — раздел **«Видео»** в основном меню:
- Создать новое видео → открывается тот же Video App, но в рамке основного layout
- Видеопроекты отображаются в общем списке контента
- Готовое видео можно сразу запланировать к публикации как обычный пост

### 5. Ошибки и уведомления

Все ошибки — человекочитаемые, с конкретным действием:

| Было | Стало |
|------|-------|
| `HTTP error 429: {"error":{"code":429...` | «Лимит Gemini исчерпан на сегодня. Переключиться на DeepSeek?» |
| `Request failed with status code 402` | «Ключ DeepSeek не активен. Проверить настройки →» |
| `Error: ECONNREFUSED` | «Сервис временно недоступен. Попробовать снова через 30 сек» |

### 6. Мобильная версия

Приоритет мобильного опыта для Telegram Mini App:
- Нижняя навигация вместо бокового меню
- Карточки с крупными touch-зонами
- Swipe-жесты для одобрения/отклонения контента
- Быстрые действия через bottom sheet

## Дизайн-система

### Цветовая схема (предложение)

```
Primary:    #6366F1  (Indigo)     — основные действия
Secondary:  #8B5CF6  (Violet)     — акценты, AI-элементы
Success:    #10B981  (Emerald)    — опубликовано, готово
Warning:    #F59E0B  (Amber)      — запланировано, ожидание
Error:      #EF4444  (Red)        — ошибки
Neutral:    #1E293B / #F8FAFC     — фон тёмный / светлый
```

### Компоненты к обновлению

| Компонент | Текущий статус | Приоритет |
|-----------|----------------|-----------|
| ContentGenerationDialog | Работает, перегружен | Высокий |
| Sidebar navigation | Плоский список | Высокий |
| ErrorToast / сообщения | Технические тексты | Высокий |
| CalendarView | Базовый | Средний |
| AnalyticsDashboard | Минимальный | Средний |
| VideoApp layout | Изолированный | Средний |
| MobileMenu | Адаптировано частично | Низкий |

## Приоритеты редизайна

### Фаза 1 — Быстрые улучшения (без архитектурных изменений)
1. Человекочитаемые сообщения об ошибках ✅ (частично сделано)
2. Упрощение ContentGenerationDialog — убрать лишние поля
3. Группировка пунктов меню по смыслу
4. Карточки контента с чётким статусом и следующим действием

### Фаза 2 — Новый флоу создания контента
1. Wizard «Создать пост» в 3 шага
2. Интеграция Video App в основной UI
3. Обновлённый календарь с drag & drop

### Фаза 3 — Новый дашборд и мобильный опыт
1. Главный дашборд с daily digest
2. Нижняя навигация для Telegram Mini App
3. Swipe-карточки для одобрения контента в controlled-режиме
