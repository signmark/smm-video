## 2. Статус аналитики: макет («рыба»)

Раздел аналитики на июль 2026 — заполнение интерфейса функционалом, не боевая фича. Цифрам не доверять, всерьёз не воспринимать, приоритет связанных с ней долгов — минимальный. Заметки ниже актуализировать, когда/если аналитика станет настоящей:

- **Перезапись метрик скрейпером** (`server/services/analytics-service.ts`, `supplementFromScraper`): при ≥1 совпавшем посте метрики платформы заменяются скрейперной суммой. Сейчас безопасно — других писателей `platformData.analytics` нет. Вернуться, если появится второй источник аналитики: перейти на merge/max по постам.
- **Синхронный `/api/analytics/update`**: запрос ждёт полного цикла скрейпера (`force: true`). При росте числа каналов или деградации скрейпера возможны таймауты прокси (Traefik). Если всплывут — перейти на паттерн «запустил задачу → клиент поллит статус».
