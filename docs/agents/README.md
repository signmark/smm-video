## Три железных правила (дублируются во всех профилях)

1. **Исполнитель ≠ ревьюер.** Каждое изменение кода видят минимум две разные модели.
2. **Не верь чужому «зелёное».** Ревьюер и деплоер гоняют тесты сами.
3. **Single-writer.** Один файл — один пишущий агент одновременно. Чужой WIP не трогать.

## Как обновлять

Профили ведёт Mavis (зона docs/). Изменение ролей — только через owner-gate + обновление таблицы зон в `AGENTS.md`.
