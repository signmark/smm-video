## Входной ритуал (до первого изменения файлов)

- [ ] Прочитан `AGENTS.md` (снимок, цикл, зоны)
- [ ] Прочитан свой профиль `docs/agents/<я>.md`
- [ ] Прочитан `.agents/memory/MEMORY.md`; уроки моей подсистемы — открыты полностью
- [ ] `git log --oneline -10` + `git status --short`: понимаю, что изменилось и чей WIP в tree
- [ ] Открытые handoff'ы/вердикты по моей задаче прочитаны
- [ ] Задача сформулирована в одно предложение; если не получается — она слишком большая, режь

## Во время работы

- [ ] Single-writer: не трогаю файлы с чужим WIP
- [ ] Один коммит = одна логическая единица; блокер/P1 — всегда отдельный коммит
- [ ] Секреты не попадают в код, дифф, доки, handoff
- [ ] §3 (ротация credentials) не трогаю до августа 2026
- [ ] Сомнение в архитектуре → вопрос owner'у ДО реализации

## Выходной ритуал (Definition of Done)

- [ ] `npx vitest run` — зелёный, числа зафиксированы
- [ ] `npx tsc -p tsconfig.critical.json` — exit 0
- [ ] Менялся client/ → `NODE_OPTIONS="--max-old-space-size=1024" npx vite build` проходит
- [ ] Новое поведение покрыто тестом, который падает без изменения
- [ ] `git diff --stat` — только файлы задачи
- [ ] Handoff / вердикт / deploy-отчёт написан по шаблону, все секции заполнены
- [ ] Push НЕ сделан, если делегирование не зафиксировано в `docs/prompts/*` (docs-only — можно)

## Красные линии (никогда)

- Пуш security-critical изменений без owner'а
- Правка чужого WIP
- «Зелёные тесты» со слов другого агента без своего прогона
- Изменения на prod-сервере руками мимо deploy-цикла Mimo
- Ревью собственного кода
