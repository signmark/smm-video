### Первичная аудитория (Early Adopters)
- **SMM-специалисты фрилансеры** - работают с 3-10 клиентами, нуждаются в автоматизации

- **Частные маркетологи** - ведут соцсети для малого бизнеса

### География
- Россия, Беларусь, Казахстан, Украина
- Русскоязычные специалисты

### Критерии квалификации лида
✅ Публично указывает профессию SMM/маркетолог  
✅ Активен в профессиональных сообществах  
✅ Имеет контактные данные (Telegram, email, LinkedIn)  
✅ Работает с соцсетями ВК, Telegram, Instagram

## Каналы коммуникации

### 1. Telegram (основной канал)
**Преимущества:**
- Высокая открываемость (60-80%)
- Персонализированный контакт
- Прямой отклик

**Формат:**
- Личное сообщение от бота или аккаунта
- Персонализация по имени/нише
- Короткое (2-3 предложения) + CTA

**Лимиты:**
- 20-30 новых диалогов/день с одного аккаунта
- Использовать 3-5 аккаунтов для масштаба
- Интервал 2-3 минуты между сообщениями

**Автоматизация:**
- Telegram Bot API для отправки
- Очередь сообщений в Directus
- Трекинг откликов и статусов

### 2. Email
**Преимущества:**
- Профессиональный канал
- Можно включить лендинг/кейсы
- Легко автоматизировать

**Формат:**
- Персонализированное письмо
- Тема: "Сэкономьте 10 часов в неделю на SMM"
- HTML-шаблон с визуалом

**Инструменты:**
- Sendgrid Free (100 писем/день)
- Mailgun Free (10,000 писем/месяц первые 3 месяца)
- Собственный SMTP через Node.js

**Лимиты:**
- Начать с 50-100 писем/день
- Постепенно увеличивать для прогрева домена
- Мониторить bounce rate (<5%)

### 3. LinkedIn InMail
**Преимущества:**
- Профессиональный контекст
- Высокая конверсия в b2b

**Формат:**
- Короткое приглашение
- Упор на ROI и автоматизацию

**Лимиты:**
- Premium аккаунт: 5-10 InMail/месяц бесплатно
- Использовать аккуратно для топ-лидов

### 4. ВКонтакте личные сообщения
**Формат:**
- Короткое приветствие
- Ссылка на демо

**Лимиты:**
- 20-30 сообщений/день
- Избегать спам-фильтров

## Юридические аспекты и compliance

### Соблюдение законодательства РФ

**Закон "О рекламе" (№38-ФЗ):**
- ❌ Запрещена массовая рассылка без согласия (спам)
- ✅ Разрешены персонализированные B2B-приглашения
- ✅ Контакты из публичных источников = законно
- ✅ Обязательна опция отписки

**Закон "О персональных данных" (№152-ФЗ):**
- Обработка публичных данных без согласия — легитимна
- Хранить источник получения контакта
- Обеспечить удаление по запросу
- Документировать законное основание

### GDPR (для международных контактов)

**Legitimate Interest (законный интерес):**
- B2B коммуникация = допустима
- Документировать оценку интересов (Legitimate Interest Assessment)
- Право на отписку и удаление данных
- Прозрачность: указать источник контакта

### Практические правила

**✅ Можно:**
- Персонализированные приглашения в Telegram
- Email на публичные рабочие адреса
- LinkedIn InMail для B2B
- Указание источника: "Нашёл ваш профиль на..."

**❌ Нельзя:**
- Массовая рассылка без персонализации
- Повторная отправка после отказа
- Использование покупных баз данных
- Скрытие отправителя

**Обязательно в сообщении:**
- Кто отправитель
- Откуда контакт
- Опция отписки: "Не интересно? Напишите 'стоп'"
- Прозрачность: "Нашёл ваш канал в TGStat"

### Хранение данных в Directus

**Таблица `leads` должна включать:**
- `source` — откуда получен контакт (TGStat, LinkedIn, FL.ru)
- `consent_date` — дата сбора
- `opt_out` — флаг отписки
- `last_contact` — дата последнего контакта
- `notes` — основание обработки ("публичный профиль", "бизнес-контакт")

**Процесс отписки:**
- Команда "стоп" в Telegram → `opt_out: true`
- Ссылка "Unsubscribe" в Email → удаление из базы
- Хранить историю отписок минимум 3 года

## Риски и митигация

### Риск 1: Низкая конверсия (<2%)
**Причины:**
- Нерелевантная аудитория
- Слабый оффер
- Плохой таргетинг

**Митигация:**
- A/B тестирование сообщений
- Уточнение ICP (Ideal Customer Profile)
- Добавление социальных доказательств
- Улучшение лендинга

### Риск 2: Блокировки за спам
**Причины:**
- Превышение лимитов
- Жалобы пользователей
- Детекция автоматизации

**Митигация:**
- Строгие лимиты (20-30 сообщений/день/аккаунт)
- Персонализация каждого сообщения
- Задержки между отправками (2-3 минуты)
- Использование разных IP/аккаунтов
- Опция отписки в каждом сообщении

### Риск 3: Юридические проблемы
**Причины:**
- Нарушение GDPR / №152-ФЗ
- Жалобы на спам
- Использование данных без согласия

**Митигация:**
- Только публичные контакты
- Документирование источников
- Опция отписки
- Хранение согласий и оснований
- Консультация с юристом перед запуском

### Риск 4: Низкое качество лидов
**Причины:**
- Неточная фильтрация
- Устаревшие контакты
- Нецелевая аудитория

**Митигация:**
- Ручная верификация первых 100 лидов
- Мониторинг bounce rate (<5%)
- Сегментация по активности
- Постоянная очистка базы
