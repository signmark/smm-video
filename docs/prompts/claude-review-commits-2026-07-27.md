## P1 — безопасность/корректность

- [x] **SSRF через redirect в `/api/proxy-image`**
  (`server/routes/proxy-image.ts`). `axios` с `maxRedirects: 2` следует за
  30x БЕЗ ревалидации цели: публичный URL может ответить
  `302 → http://169.254.169.254/...` и блок-лист обходится. Плюс DNS-вариант:
  эндпоинт публичный, `isBlockedHost` проверяет только литеральные IP —
  доменное имя атакующего, резолвящееся в приватный IP, проходит проверку.
  Фикс: `beforeRedirect`-ревалидация каждого хопа + DNS pre-check
  (`dns.lookup`, все адреса должны быть публичными). Остаточный риск —
  TOCTOU-ребиндинг между проверкой и запросом; для картиночного прокси
  принимаем, зафиксировано здесь.

- [x] **`/api/proxy-image` отдаёт произвольный content-type с нашего origin**.
  Апстрим может вернуть `text/html` — атакующий получает свою страницу,
  хостящуюся на домене приложения (фишинг/обход same-origin эвристик).
  Фикс: allowlist `image/*` (+ `video/*` — прокси исторически используется и
  для превью видео) → иначе 502; всегда `X-Content-Type-Options: nosniff`.

- [x] **`AutonomousLaunchDialog`: успех-тост при упавшем старте**
  (`client/src/components/AutonomousLaunchDialog.tsx`). `mutationFn` не
  проверяет `res.ok`/`data.error` — сервер вернул 400/500 (`{error}`), а
  onSuccess всё равно сработал: тост «Агент запущен», диалог КП закрыт, агент
  не запущен. Фикс: throw на `!res.ok || data.error` + `onError`-тост.
  То же самое было в Topbar — ушло вместе с дублем (см. ниже).

## P2 — корректность/дубли

- [x] **Cache-buster `_t=Date.now()` обнуляет новый `Cache-Control`**
  (`client/src/pages/trends/lib/trends-view.ts`). Сервер теперь шлёт
  `public, max-age=86400`, но `_t` меняется на каждый маунт страницы → браузер
  заново качает ВСЕ превью через прокси при каждом заходе. Параметры
  `forceType`/`itemId` мёртвые — новый роут их игнорирует. Фикс: URL прокси
  без `_t` и мёртвых параметров (ретрай `&_retry=true` в карточке оставлен —
  он и нужен, чтобы обойти закэшированную ошибку).

- [x] **Дубль диалога запуска агента**. Новый `AutonomousLaunchDialog`
  скопирован с inline-диалога в `Topbar.tsx` (вплоть до одинакового
  `data-testid="dialog-pipeline-mode"` и текстов MODES), а Topbar на общий
  компонент не переведён — две копии немедленно начнут расходиться.
  Фикс: Topbar использует `AutonomousLaunchDialog`, inline-копия и её
  мутация удалены (~90 строк).

- [x] **`allowedContentTypes` может исключить явно выбранный тип**
  (`server/services/content-plan-generator.ts`). При `contentType:
  'text-image'` и выключенной галке картинок клиент шлёт
  `includeImages: false` → allowed = `['text']`, и промпт противоречит сам
  себе: «используй text-image для всех постов» vs «contentType строго одно
  из: text». Аналогично `image`. Фикс: конкретный выбранный системный тип
  всегда включается в allowed-список.

- [x] **Смарт-режим (`aiDecidesCount`) минует чанкинг трендов**. Обычный путь
  режет тренды по `MAX_CHARS_PER_CHUNK`, смарт-режим склеивает ВСЕ выбранные
  тренды в один промпт — на большом выборе промпт превысит лимит запроса.
  Фикс: тренды добираются в промпт до бюджета, излишек отбрасывается с
  логом (`log()`), количество отброшенных видно в прогрессе.
