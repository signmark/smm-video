## Калибровка MiniMax (и любых новых участников)

Первая задача — с ограниченным радиусом поражения (Task C: только
тест-файлы, прод не затрагивается, приёмка машинно-проверяема).
Оценка сдачи по чек-листу:

1. **Полнота** — все пункты ТЗ закрыты, `git grep` по критериям приёмки чист.
2. **Дисциплина скоупа** — не полез «улучшать» соседнее; out-of-scope
   находки — отдельным сообщением, не правкой.
3. **Качество по сути, не по форме** — для C особо: моки не подогнаны под
   зелёный цвет ценой смысла теста; ковровый `it.skip` запрещён промптом.
4. **Честность отчёта** — полный `npx vitest run` до/после, преждесуществующие
   падения отмечены явно, дельта против `baseline-vitest-2026-07-19.txt`.

Чистая сдача → перевод в основной ростер, вторая задача уровнем выше
(Task 8 — один файл прод-кода с сильным тестовым покрытием).
Грязная сдача → разбор, вторая калибровочная попытка на задаче того же
класса. Два провала подряд — вопрос к владельцу о составе.
