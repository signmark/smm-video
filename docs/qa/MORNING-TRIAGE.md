## 🔴 Открыто — по убыванию важности

### 1. Права роли `SMM Manager User` в Directus (следствие F-1)
Фикс F-1 закрыл утечку **через наш API**, но роль по-прежнему читает `campaign_content_sources`,
`campaign_keywords`, `campaign_trend_topics` **целиком** напрямую в Directus (в обход API).
Нужен фильтр через связь `{"campaign_id":{"user_id":{"_eq":"$CURRENT_USER"}}}`. **Не вслепую:**
сперва проверить, зарегистрирован ли `campaign_id` как M2O-отношение (`GET /relations?...`), иначе
фильтр молча не сработает. Порядок — в журнале, раздел 6.

### 2. F-20 (P2) — вебхук YooKassa доверяет метаданным из тела → бесплатный Pro
`POST /api/yookassa/webhook` берёт `user_id`/`plan` из тела, проверяя у YooKassa только факт
оплаты. Зарегистрированный юзер с ID реального платежа получает Pro. Фикс: брать из
`verified.metadata`, как уже делает `/payments/:paymentId/activate`. Связка с F-21: если делать
вебхук публичным для реальных колбэков — чинить F-20 одновременно. Задача #7.

### 3. F-22 (P2 для твоего случая) — 24ч-токен не отзывается
Смена пароля и logout **не гасят** выданный access-токен (живёт 24ч). Для админского аккаунта с
утраченным ящиком: если сессия уже угнана, смена почты+пароля не выкинет атакующего до суток.
Немедленная защита — отзыв сессий в Directus. Долгосрочно — короткий access-TTL + version-claim.
Задача #8. См. также раздел 9 журнала (шаги по защите аккаунта).

### 4. F-17 (P2) — гонка в погашении промокода → бесплатный Pro
`POST /api/promo/redeem`: проверка «уже использовал»/`max_uses` не атомарна с записью.
Параллельные запросы обходят лимит. Фикс: уникальный индекс `(promo_code_id,user_id)` +
атомарный инкремент. Задача #6.

### 5. F-13 (P2) — горизонтальный скролл на мобильной ширине
`/content`, `/analytics`, `/publish/scheduled` едут вбок на 380px: ряд иконок в шапке
(`Topbar.tsx`) не сжимается + селектор кампании. Задача #4.

### 6. F-8 (P2, данные) — 340 из 845 «опубликованных» постов без `published_at`
Причина найдена и **новые публикации починены** (3 пути), но исторические 340 записей теряются
во всех разрезах по времени (график активности, отчёты). Досчёт истории признан невозможным
достоверно; скрипт-бэкфилл лежит в `scripts/maintenance/`, dry-run, **не запускался**.
