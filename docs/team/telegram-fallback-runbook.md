# Runbook — запасные адреса Telegram (TELEGRAM_API_IPS)

Одна страница. Что делать, когда отказоустойчивый транспорт Telegram переходит на
запасные адреса.

## Когда это сработало

Failover-транспорт (`server/services/social-platforms/telegram-http.ts`) резолвит
адреса `api.telegram.org` через DNS, а при отказе/пустом ответе добавляет адреса из
переменной `TELEGRAM_API_IPS`. Если соединение установилось через адрес НЕ из DNS —
в логах и в WebSocket-уведомлении приходит сигнал:

- **`запас спас`** — запасной адрес ответил после отказа DNS (`kind: saved`).
- **`запас протух`** — запасной адрес реально пробовали, но он не ответил (`kind: stale`).

Оба сигнала rate-limited ~1 час на один адрес и, кроме stdout-лога, рассылаются в
UI как `broadcastNotification('telegram_failover', …)`.

## Где смотреть

1. Лог приложения: `grep 'telegram-transport' <лог>` — там строки
   `запас спас: …` / `запас протух: …` / `TELEGRAM_API_IPS не задана …`.
2. UI/WebSocket: событие `telegram_failover` с полями `kind`, `detail`, `timestamp`.

## Как проверить, что список адресов актуален

```bash
TELEGRAM_API_IPS=149.154.167.220,149.154.166.110 \
  node scripts/telegram-fallback-freshness.mjs
```

Вывод по каждому адресу — `fresh` или `STALE` с причиной (таймаут/код ошибки).
`exit 0` — есть хотя бы один живой адрес; `exit 1` — ни одного (список протух, его
надо обновлять).

## Как обновить список

1. Найти живые адреса `api.telegram.org` (например `getent ahostsv4 api.telegram.org`
   с хоста, плюс известные резервные адреса), проверить каждый зондом выше.
2. Обновить `TELEGRAM_API_IPS` в `/root/.env` (или в конфиге выката) списком через
   запятую. Порядок не важен: DNS-адреса в переборе идут первыми, дубли схлопываются.
3. Перезапустить приложение, чтобы переменная подхватилась.
4. Проверить зондом, что новые адреса `fresh`.

## Чего НЕ делать

- **Не снимать пин `/etc/hosts`** — закрепление текущего адреса остаётся как есть и
  не связано с этой задачей.
- Не менять `TELEGRAM_API_IPS` на имена хостов — только IPv4.
- Не отключать `rejectUnauthorized` в зонде — он должен проверять сертификат так же,
  как транспорт.
