# SMM Manager - Статический Landing Page

## 🔧 Конфигурация для разных клиентов

Для удобного переключения между клиентами или копиями платформы используется файл **`config.js`**.

### Как изменить URL для другого клиента:

1. Откройте файл **`config.js`**
2. Измените значение `appUrl`:

```javascript
const APP_CONFIG = {
    appUrl: 'https://smm.omemo.tech',  // ← Измените этот URL
};
```

### Примеры URL для разных клиентов:

```javascript
// Клиентская версия (текущая)
appUrl: 'https://smm.omemo.tech'

// Ваша личная копия (будущая)
appUrl: 'https://smm.omemo.tech'

// Dev-версия
appUrl: 'https://smm.roboflow.space'
```

---

## 📁 Структура файлов

- **`config.js`** - Конфигурация URL (меняйте здесь для разных клиентов)
- **`index.html`** - Главная страница
- **`script.js`** - JavaScript логика (использует URL из config.js)
- **`styles.css`** - Стили
- **`privacy.html`** - Политика конфиденциальности
- **`terms.html`** - Пользовательское соглашение
- **`cookies.html`** - Политика cookies

---

## 🚀 Развертывание

При деплое на новый сервер:

1. Скопируйте все файлы из папки `smmniap_static/`
2. Измените URL в `config.js` на нужный
3. Готово! Все кнопки будут вести на новый URL

---

## 🔗 Где используется URL из конфига:

- Кнопка "Попробовать бесплатно" в шапке
- Кнопка "Попробовать бесплатно" в Hero секции
- Кнопки тарифов "Начать бесплатно" и "Начать пробный период"
- Кнопка "Начать бесплатно" в CTA секции
- Ссылка "Войти" в footer

Все эти кнопки автоматически открывают URL из `config.js`.
