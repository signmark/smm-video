# Концепция редизайна: Viral Content Creation Platform

## Ключевой сдвиг

Убрать поле "введите промт" с главной. Стартовый экран — выбор **цели** (Viral / Promo / Brand / WTF и т.д.).
Пользователь думает не о технологии, а о результате.

**"WTF Mode"** — отдельная точка входа с тёмной эстетикой. Генерирует не видео, а *момент*.
Это сильный дифференциатор и виральный механик сам по себе.

**AI Creative Director** — не просто генерация, а диалог. После выбора цели AI задаёт 2-3 вопроса
(аудитория? тон? платформа?) и строит стратегию.

**Virality Score** — предиктивная оценка до рендера. Пользователь может переработать сценарий,
не тратя время на генерацию.

## Алгоритм (шаблон реализации)

```
1. GOAL SELECTION
   └─ UI: карточки с целями (иконка + описание outcome)
   └─ Сохранить: goal_type, platform_target (TikTok / YouTube / Reels)

2. STRATEGY GENERATION (AI)
   └─ Input: goal + brief answers (аудитория, тон, платформа)
   └─ Output: hook, tension, payoff, CTA, emotional_arc
   └─ UI: показать стратегию, дать редактировать каждый элемент

3. STORY BUILDER (AI → storyboard)
   └─ N сцен (обычно 5-8 для 30-60 сек)
   └─ Каждая сцена: цель / нарратив / визуальный промт / эмоция / длительность
   └─ UI: карточки сцен, drag-n-drop переупорядочивание

4. ASSET RESOLUTION (уже реализовано частично)
   └─ Stock precheck (Pexels) → AI image (Imagen/Gemini) → FAL animation
   └─ Стиль-локер: задать style_prompt один раз, применять ко всем AI-сценам

5. ASSEMBLY (уже есть)
   └─ TTS → clips → ffmpeg → music mix

6. VIRALITY ANALYSIS (AI post-generation)
   └─ Input: сценарий + структура видео
   └─ Output: hook_score, retention_score, shareability, cta_score
   └─ UI: радар-чарт + конкретные рекомендации ("первые 3 сек слабые — переделать?")

7. EXPORT / SHARE
   └─ Download MP4
   └─ (будущее) прямая публикация через основной SMM модуль
```

## WTF Mode — промт-шаблон для сценариста

```
Жанр: киберпанк / абсурдизм / экзистенциальный юмор
Стиль: короткие ударные фразы, разрыв ожиданий
Структура: утверждение → парадокс → тихий вывод
Визуал: тёмный, неоновый, глитч, slow-mo
Пример паттерна:
  "[Действие системы]."
  "[Неожиданный результат]."
  "[Состояние пользователя]."
  "[Парадоксальный вывод]."
```

## Технические точки риска

**Стиль-консистентность** — самое сложное. Wan 2.7 / Kling не гарантируют единый визуальный
стиль между сценами. Решение: жёсткий `style_prompt` в каждом image-промте + seed если модель
поддерживает.

**Virality Score** — не делать через анализ видео (дорого и медленно). Делать через анализ
сценария текстом (Gemini/Claude) — быстро и достаточно точно для MVP.

**WTF Mode** — нужен отдельный системный промт для сценариста: абсурдизм + киберпанк-эстетика
+ короткие ударные фразы. Хранить в конфиге, не хардкодить.

## Порядок реализации (приоритет)

1. **Шаги 1-3** (Goal → Strategy → Storyboard) — максимум UX-ценности, не требуют изменений
   в пайплайне генерации. Новый UI flow поверх существующего.
2. **Style Locker** — добавить `style_prompt` в проект, прокидывать во все image-промты.
3. **Virality Analysis** — текстовый AI-анализ сценария после его создания.
4. **WTF Mode** — отдельный маршрут/промт, тёмная тема UI.
5. **Публикация в SMM** — интеграция с основным модулем.
